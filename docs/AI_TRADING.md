# AI 实盘交易 — 概念辨析与实践路径

## "AI 交易"的四个层次

### 第一层：AI 当幌子

很多所谓"AI 交易"就是传统技术指标策略（均线、RSI、MACD）套了个 AI 的壳做营销。跟手动编写的规则策略没有本质区别，只是话术不同。

### 第二层：ML 模型做信号生成

用历史 OHLCV 数据训练模型（LSTM、XGBoost、Transformer 等），输入过去 N 根 K 线的价格和成交量，输出未来方向（涨/跌/平）或收益率预测。模型给出的预测转换为交易信号。

**核心挑战：**

- **过拟合**：回测曲线完美，实盘一塌糊涂。金融数据的信噪比极低，模型很容易记住噪声而非学习规律
- **市场状态漂移**：牛市训练的模型到熊市直接废掉。市场规律不是平稳的，数据分布随时间剧烈变化
- **信号到执行的 gap**：模型预测涨 0.1% 和真正下单赚钱是两回事。还需要考虑滑点、手续费、冲击成本

### 第三层：强化学习做决策

RL 智能体在历史数据模拟环境中试错，学习什么时候买、卖、持币。理论上可以学出比人工规则更优的策略。

**实际困难：**

- 金融市场不是马尔可夫过程，历史不会简单重复
- reward 函数极其难设计——Sharpe vs 总收益 vs 回撤，权重怎么定？不同的 reward 导向完全不同的行为
- 模拟环境和真实市场差距太大（滑点、延迟、订单簿深度），在仿真中学到的东西迁移不到实盘
- 训练样本效率低，一个 episode 就是一个月甚至一年的行情

### 第四层：LLM Agent 做交易

让 GPT/Claude 等模型阅读新闻、财报、链上数据，输出交易决策。目前有一些学术论文，效果随机性很大，距离稳定盈利还很远。

---

## 两个核心矛盾

### 1. 竞争不对等

金融市场是零和的（严格说是负和的，扣除手续费）。你的对手是 Jane Street、Citadel、Jump Crypto、DRW 这些：
- 数百人的全职团队（PhD 扎堆）
- 数千万美元的算力集群和低延迟基础设施
- 直连交易所的 colocation 机房

一个 LSTM 模型跑在自己电脑上的边缘在哪里？

**可能的回答：** 机构不做小币种，机构的策略容量有限，机构的交易成本（合规、人力）比个人高。在细分领域（山寨币、低时间框架）可能存在机构不屑于参与的 alpha。但只是"可能"。

### 2. 黑箱 VS 信仰

规则策略亏钱时你知道为什么——均线交叉策略在震荡市就是会反复亏。你可以理智地判断"是市场不适合这个策略"还是"策略逻辑有 bug"。

AI 模型亏钱时你分不清是模型错了还是市场噪声大了。止损全靠信仰，信仰一旦动摇就容易在最低点关掉模型，而后它可能刚好回归。这种心理压力比规则策略大得多。

## 实际可行的路径

### 当前阶段：跑稳基础设施

把规则策略的完整链路先跑通：

```
数据获取 → 回测验证 → 模拟盘验证 → 小额实盘
```

赚到第一笔钱之后，才有信心和基础去做更复杂的事。

**这意味着一套可复用的基础设施已经就绪：**
- 数据管道已经跑通，Parquet 里存了够多的 OHLCV 数据
- 回测引擎能出 Sharpe、MaxDD、Calmar 等指标
- 模拟盘能接入实时数据验证策略稳定性
- 风控系统能在策略失效时兜底

### 下一步：AI 辅助，而非 AI 替代

比较务实的方向是让 AI 增强现有规则的某个环节，而非端到端替代：

1. **NLP 情绪信号 → 调整策略置信度**
   从新闻/推特提取市场情绪，作为传统策略的附加权重。例如 RSI 均值回归策略正常情况下 confidence=0.5，当情绪极度恐慌时 confidence 提到 0.8。

2. **ML 做波动率预测 → 动态仓位调整**
   训练一个模型预测未来 N 小时的波动率。波动率高时自动减仓，波动率低时正常仓位。这个任务比预测价格方向容易得多。

3. **异常检测 → 风控增强**
   用无监督学习（Autoencoder、Isolation Forest）实时检测市场异常模式。当检测到异常时自动减仓或暂停策略。这种"什么时候不做"比"什么时候做"更容易学。

### 最终形态：ML 模型驱动策略

当基础设施跑稳、AI 辅助模块验证有效后，可以尝试将 `Strategy.on_bar()` 从手写规则替换为 ML 模型推理：

```python
class MLStrategy(Strategy):
    def __init__(self, ...):
        self.model = load_model("lstm_predictor.onnx")

    async def on_bar(self, symbol: str, bar: OHLCV) -> Signal | None:
        features = self._extract_features(symbol)
        prediction = self.model.predict(features)
        if prediction > threshold:
            return Signal(symbol=symbol, side=OrderSide.BUY, ...)
```

其他所有基础设施（数据管道、回测引擎、模拟盘、风控、实盘执行）完全不变。**只有策略内部从规则变成了模型，外层不变。** 这才是真正有意义的"AI 交易"——不是推倒重来，而是在经过验证的系统上做增量升级。

---

## 结论

"AI 实盘交易"不是一个开关，不是一个产品。它是一个分阶段的推进过程：

1. 跑稳规则策略的基础设施（**← 当前阶段**）
2. 用 AI 辅助单个环节（情绪、波动率、风控）
3. 将策略核心从规则替换为模型

每一步都需要在实盘上验证，每一步都独立可回滚。不要一步到位，不要推倒重来。
